## 🌟 これは何？/ 这是什么

**日本語**:
日本の就職活動では、何十社もの企業の説明会・ES締切・Webテスト・面接が同時並行で進みます。それぞれの企業からメールが届き、マイページの URL や ID もバラバラ。「どの企業がどの選考段階で、次に何をすべきか」を把握するのは大変です。

このアプリは、**チャットで話しかける**か**企業からのメールを貼り付ける**だけで、AI が日時・場所・要点・ログイン情報を自動で抽出し、予定・メモ・進捗ボードに整理します。Google Calendar と連携してスマホに通知も届きます。

**中文**:
日本求职过程中，几十家公司的说明会、ES 截止、笔试、面试同时进行。每家公司发来邮件，マイページ 的 URL 和 ID 又各不相同。要搞清楚「哪家公司走到哪一步、下一步该做什么」非常麻烦。

这个应用，只需**在聊天里说话**或**粘贴企业邮件**，AI 就自动提取时间、地点、要点、登录信息，整理进日程、备忘录和进度看板。还能联动 Google Calendar，让手机收到通知。

## 🚀 はじめ方 / 快速上手

### ステップ1: Groq API キーを取得 / 第1步：获取 Groq API key
**日本語**: [console.groq.com/keys](https://console.groq.com/keys) にアクセスし、無料でキーを作成します。AI（言葉を予定に変換する頭脳）に必要です。

**中文**: 访问 [console.groq.com/keys](https://console.groq.com/keys)，免费创建一个 key。这是 AI（把语言转成日程的大脑）必需的。

### ステップ2: 設定でキーを入力 / 第2步：在设定里输入 key
**日本語**: 画面右上の ⚙️ 設定 を開き、Groq API キーを貼り付けて保存。

**中文**: 打开右上角 ⚙️ 設定，粘贴 Groq API key 并保存。

### ステップ3: Google Calendar 連携（任意）/ 第3步：Google 日历联动（可选）
**日本語**: 設定画面の「Google アカウントで連携する」をクリックして認証。予定がカレンダーに自動追加され、スマホに通知が届くようになります。
**中文**: 点击设定里的「Google アカウントで連携する」授权。日程会自动加到日历，手机会收到通知。

### ステップ4: クラウド同期を設定（強く推奨）/ 第4步：设置云同步（强烈推荐）
**日本語**: 設定で「クラウド同期パスワード」を入力。これでデータがクラウドに保存され、別の端末でも同じパスワードで復元できます。**このパスワードは絶対に忘れないでください。**
**中文**: 在设定里输入「クラウド同期パスワード」。这样数据会存到云端，换设备用同样密码就能恢复。**这个密码千万别忘。**

### ステップ5: 使ってみる / 第5步：开始使用
```
明日15時にトヨタの面接がある
ソニーのES締め切りは来週金曜日
（Accentureのwebテスト案内メールを丸ごと貼り付け）

## 🔍 機能の詳細 / 功能详解

### 💬 チャットで予定登録 / 聊天加日程

**日本語**:
- 「明日15時にトヨタの面接」のような自然な言葉から、会社名・種類（面接/ES/説明会/筆記/その他）・日時を自動抽出
- 複数の予定を一度に登録可能（例：「来週月曜にA社の面接、金曜にB社のES締切」）
- 企業からのメールを丸ごと貼り付けると、日時・場所・要点・マイページのURL/ID/ログイン情報まで抽出
- 日時が読み取れない場合は、AI が推測せず質問してくれる
- 確認カードで内容を確認してから「登録」

**中文**:
- 从「明日15時にトヨタの面接」这样的自然语言中，自动提取公司名、类型（面接/ES/説明会/筆記/その他）、时间
- 可一次登记多个日程（例：「来週月曜にA社の面接、金曜にB社のES締切」）
- 粘贴整封企业邮件，能提取时间、地点、要点、マイページ 的 URL/ID/登录信息
- 读不出时间时，AI 不会瞎猜，而是反问你
- 在确认卡片上核对内容后再点「登録」

### 🏠 今日ダッシュボード / 今日首页

**日本語**: アプリを開くと最初に表示される画面。時間帯に応じた挨拶、今日の予定数・今週の予定数・選考中の企業数、そして「⚠️ 今日」「📅 今週」の予定リストが表示されます。緊急度に応じて色分け（赤=今日、黄=2日以内、緑=それ以降）。
**中文**: 打开 app 第一眼看到的画面。根据时段问候，显示今日/本周日程数、选考中公司数，以及「⚠️ 今日」「📅 今週」的日程列表。按紧急度配色（红=今天，黄=2天内，绿=更晚）。

### 📅 カレンダー / 日历

**日本語**: 月単位のカレンダー表示。各日に予定が色付きのラベルで表示され、クリックすると詳細モーダルが開きます。月の前後移動も可能。
**中文**: 月历视图。每天的日程以彩色标签显示，点击打开详情弹窗。可前后翻月。

### 📝 メモ / 备忘录

**日本語**:
- 2種類のメモ：自由形式の「普通のメモ」と、企業に紐づく「企業別メモ」
- 企業別メモには 🔑 マイページ情報（URL・ID・パスワードのヒント）を保存可能。URL はクリックで開け、ID はワンタップでコピー
- 本文中の URL は自動でクリック可能なリンクに変換（デフォルトでリンク表示モード、編集したいときは「✏️ 編集」に切替）
**中文**:
- 两种备忘录：自由形式的「普通のメモ」，和绑定公司的「企業別メモ」
- 企业别 memo 可保存 🔑 マイページ情报（URL、ID、密码提示）。URL 可点击打开，ID 可一键复制
- 正文里的 URL 自动变成可点击链接（默认链接显示模式，想编辑时切到「✏️ 編集」）

### 📊 進捗ボード / 进度看板

**日本語**: 企業ごとにカードを作り、選考の進み具合をドラッグ＆ドロップで管理。9段階：
**中文**: 每家公司一张卡片，用拖拽管理选考进度。9个阶段：

```
気になる・説明会 → OB・OG訪問 → ES提出 → Webテスト → GD
→ 一次面接 → 二次面接 → 最終面接 → 内定
```

**日本語**: 各カードには次の予定（例：「📅 面接 6/5」）とメモのプレビューが表示されます。
**中文**: 每张卡片显示下一个日程（例：「📅 面接 6/5」）和备忘录预览。

### 🏢 企業詳細ページ / 公司详情页

**日本語**:
進捗ボードの企業カードをクリックすると、その企業に関する全情報が一画面に集約されます：
- 選考ステージ（ドロップダウンで変更可）
- 📅 関連する全予定（チャットで登録したものが自動的に表示）
- 🔑 マイページ情報（URL・ID・ログインメモ）
- 📝 自由メモ

**会社名の曖昧マッチング**: 「トヨタ」と「トヨタ自動車」、「Accenture」と「アクセンチュア」など、表記が違っても自動的に同じ会社と認識して紐付けます。株式会社・グループ等の接尾辞、全角半角、大文字小文字、英語↔カタカナの主要企業も対応。

**中文**:
点击进度看板的公司卡片，该公司的全部信息汇集在一个页面：
- 选考阶段（下拉可改）
- 📅 所有相关日程（聊天登记的会自动显示）
- 🔑 マイページ情报（URL、ID、登录备注）
- 📝 自由备忘录

**公司名模糊匹配**: 「トヨタ」和「トヨタ自動車」、「Accenture」和「アクセンチュア」，即使写法不同也自动识别为同一家并串联。支持去除「株式会社」「グループ」等后缀、全角半角、大小写、英文↔片假名主要企业对照。

### 🔔 Google Calendar 連携 / Google 日历联动

**日本語**:
- 予定を登録すると、自動的に Google カレンダーにも追加（リマインダー付き）
- スマホの標準通知機能でリマインドされるので、見逃しを防げる
- アクセストークンは45分ごとにバックグラウンドで自動更新。一度認証すれば再ログイン不要
- 予定を削除すると、Google カレンダーからも自動的に削除
**中文**:
- 登记日程后，自动加到 Google 日历（带提醒）
- 借用手机系统通知提醒，防止错过
- access token 每45分钟后台自动更新。授权一次后无需再登录
- 删除日程时，Google 日历里的也自动删除

### ☁️ クラウド同期 / 云同步

**日本語**: 同期パスワードを設定すると、全データ（予定・メモ・企業・ゴミ箱）が Supabase クラウドに自動保存（1.5秒のディレイ後）。別の端末で同じパスワードを入力すると、データが復元されます。パスワードがデータの「鍵」なので、複雑なものを設定し、絶対に忘れないこと。
**中文**: 设置同步密码后，全部数据（日程·备忘·公司·垃圾箱）自动存到 Supabase 云端（1.5秒延迟后）。换设备输入相同密码即可恢复。密码就是数据的「钥匙」，请设复杂点且千万别忘。

### 🗑 ゴミ箱・元に戻す / 垃圾箱+撤销

**日本語**:
- 削除直後：画面下部に「↩ 元に戻す」が6秒間表示され、ワンタップで即復元
- それ以降：ナビの 🗑 ボタンからゴミ箱を開き、最新100件まで復元または完全削除が可能
- 予定・企業・メモすべてに対応
**中文**:
- 删除后立即：底部出现「↩ 元に戻す」持续6秒，一键即时恢复
- 之后：点导航的 🗑 按钮打开垃圾箱，最新100条可恢复或永久删除
- 日程、公司、备忘录全部支持

### 🔍 検索・バックアップ・その他 / 搜索·备份·其他

**日本語**:
- グローバル検索：ヘッダーの検索ボックスで予定・メモ・企業を横断検索、結果クリックで該当ページへ
- エクスポート（💾）：全データを JSON ファイルでダウンロード（定期バックアップ推奨）
- インポート（📂）：バックアップファイルから復元
- 完了した予定は灰色表示、詳細画面の「↩ 未完了に戻す」で復活可能
- 過ぎた予定は削除されず「終了」として灰色で残る
- スマホ対応：レイアウトが縦並びに自動調整

**中文**:
- 全局搜索：用顶部搜索框横跨日程·备忘·公司搜索，点结果跳到对应页
- 导出（💾）：全部数据下载为 JSON 文件（建议定期备份）
- 导入（📂）：从备份文件恢复
- 完成的日程灰显，详情页「↩ 未完了に戻す」可复活
- 过期的日程不删除，作为「終了」灰色保留
- 手机适配：布局自动改为纵向堆叠

```

        ↓
AI が抽出 / AI 提取
（日時・場所・要点・ログイン情報 / 时间·地点·要点·登录信息）
        ↓

        ↓
要点は自動でイベント詳細に保存 / 要点自动存进事件详情

        ↓
Google Calendar に追加（要点も説明欄へ）/ 加到 Google 日历（要点也写进说明）
        ↓

   ├─ 🏢 企業別メモ / 企业别 memo

   │         └─ 保存しない / 不存
   ├─ 📝 普通のメモ / 普通备忘录
   └─ 保存しない（予定だけ）/ 不存（只登记日程）
```

## 💾 データの保存と同期 / 数据存储与同步

**日本語**:
- データは3つの配列で管理：`events`（予定）、`memos`（メモ）、`companies`（企業）、加えて `trash`（ゴミ箱）
- 変更があるたびに localStorage（端末内）に保存し、同時にクラウド（Supabase）にもアップロード
- アプリ起動時にクラウドから最新データを取得
- クラウド上はパスワードをキーにしてデータを区別。別々のパスワード = 別々のデータ（友達と分けて使える）

**中文**:
- 数据用3个数组管理：`events`（日程）、`memos`（备忘录）、`companies`（公司），外加 `trash`（垃圾箱）
- 每次有改动就存到 localStorage（本地），同时上传到云端（Supabase）
- 启动时从云端拉取最新数据
- 云端用密码作为 key 区分数据。不同密码 = 不同数据（可和朋友分开用）

   alter table app_data enable row level security;
   create policy "allow all with anon key" on app_data
     for all using (true) with check (true);
   ```
6. `shukatsu-agent.html` 内の `SUPABASE_URL` と `SUPABASE_KEY` を自分のものに変更
7. デプロイ完了後、設定画面で Groq API キーを入力

## ❓ よくある質問・トラブル / 常见问题排查

**日本語**:

**Q: 「redirect_uri_mismatch」エラーが出る**
A: Google Cloud Console の承認済みリダイレクト URI と、実際のアプリの URL が一致していません。`https://あなたのアプリ.vercel.app/api/callback` が正確に登録されているか確認。

**Q: 「Calendar への追加に失敗（invalid authentication credentials）」**
A: トークンが切れています。設定画面で「Google アカウントで連携する」をもう一度クリック。ネット接続が切れていた場合も自動更新が失敗するので、再認証で解決します。

**Q: `chrome-extension://invalid/` というエラーがコンソールに出る**
A: ブラウザの拡張機能（Grammarly など）が原因で、アプリとは無関係。無視して OK。

**Q: 入力した会社名が進捗ボードに表示されない**
A: 古いバージョンの可能性。ブラウザを強制リフレッシュ（Cmd+Shift+R / Ctrl+Shift+R）。

**Q: データが消えた**
A: クラウド同期パスワードを設定していれば、同じパスワードを入力すれば復元できます。ゴミ箱も確認してください。

**中文**:

**Q: 出现「redirect_uri_mismatch」错误**
A: Google Cloud Console 里的已授权重定向 URI 和实际应用 URL 不一致。检查 `https://你的应用.vercel.app/api/callback` 是否准确登记。

**Q:「Calendar への追加に失敗（invalid authentication credentials）」**
A: token 过期了。在设定里再点一次「Google アカウントで連携する」。如果当时断网了，自动更新也会失败，重新授权即可解决。

**Q: 控制台出现 `chrome-extension://invalid/` 错误**
A: 是浏览器插件（如 Grammarly）造成的，与应用无关。忽略即可。

**Q: 输入的公司名在进度看板不显示**
A: 可能是旧版本。强制刷新浏览器（Cmd+Shift+R / Ctrl+Shift+R）。

**Q: 数据没了**
A: 如果设过云同步密码，输入相同密码即可恢复。也检查一下垃圾箱。

## ⚠️ 注意事項 / 注意事项

**日本語**:
- **クラウド同期パスワードは絶対に忘れないこと**——これがないとクラウドデータを取り出せません
- API キーやトークンはブラウザの localStorage にのみ保存され、外部に送信されません（API 通信を除く）
- クラウド同期を有効にすれば、ブラウザのキャッシュを消してもデータは安全
- 友達と使う場合は、各自で Groq キーを取得し、別々の同期パスワードを設定してください
- このアプリの URL は公開ですが、データはパスワードで区別されるため、他人にあなたのデータは見えません（複雑なパスワード推奨）

**中文**:
- **云同步密码千万别忘**——没有它无法取回云端数据
- API key 和 token 只存在浏览器 localStorage，不会外传（API 通信除外）
- 开启云同步后，即使清除浏览器缓存数据也安全
- 和朋友一起用时，各自获取自己的 Groq key，并设置不同的同步密码
- 这个应用的网址是公开的，但数据用密码区分，别人看不到你的数据（建议用复杂密码）
